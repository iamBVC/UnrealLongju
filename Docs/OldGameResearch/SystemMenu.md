# Old Client: System (ESC) Menu

Sources studied: `D:\Giochi\Metin2\Development\Dumps\my_dump\uisystem.py`,
`uiscript/systemdialog.py`, `uisystemoption.py`, `uigameoption.py`.

## Structure

- `uisystem.SystemDialog` is a `ui.ScriptWindow` loaded from `uiscript/systemdialog.py`.
  Opened/closed by the game phase when ESC is pressed or the taskbar "system" button is clicked.
- Layout (`uiscript/systemdialog.py`):
  - Window 200x258, centered on screen (`SCREEN_WIDTH/2 - 100`, `SCREEN_HEIGHT/2 - 114`), style `float`.
  - Single child `board` of type **thinboard** (16px corner/edge tiles around translucent black).
  - Vertical stack of **XLarge buttons** (`d:/ymir work/ui/public/XLarge_Button_01/02/03.sub`,
    180x25, placed at x=10): `help_button` y=17, `system_option_button` y=57,
    `game_option_button` y=87, `change_button` y=117, `logout_button` y=147,
    `exit_button` y=177, `cancel_button` y=217 (extra 40px gap before Cancel).
  - XLarge_Button sub-image regions in Public.dds: normal (0,31)-(180,56),
    over (0,56)-(180,81), down (0,81)-(180,106) — same regions already used by our
    respawn dialog generator.

## Button behavior

| Button | Old behavior |
|---|---|
| help | opens help web/window |
| system_option | opens `uiSystemOption.SystemOptionDialog` (BGM/SFX volume sliders, gamma, shadows...) |
| game_option | opens `uiGameOption.GameOptionDialog` (PvP mode, chat filters, mouse camera...) |
| change | `net.ExitGame()` → back to character select |
| logout | `net.LogOutGame()` → back to login |
| exit | `net.ExitApplication()` → closes the client |
| cancel | `self.Close()` |

Every submenu click first calls `self.Close()` on the system dialog, then opens the
sub-dialog. ESC toggling and the taskbar system button both route to
`OpenDialog()/Close()` on the singleton dialog.

## UE5 replication (this project)

`UMT2SystemMenuWidget` + `/Game/UI/MT2SystemMenu` generated by
`MT2GenerateUIBlueprintsCommandlet -SystemMenuOnly` replicate the 200-wide thinboard
with XLarge buttons: Audio, Controls, Settings, Disconnect (back to login),
Exit (quit client), Cancel — per current design the help/mall rows are dropped and
options are split into Audio/Controls/Settings pages inside the same widget.
ESC and the taskbar `SystemButton` (bottom-right) toggle it.

Page details (v2): Audio = general/music/voice-chat sliders plus capture-device and
output-device pickers (old uiSystemOption sound block, extended); Settings = per-category
scalability combos (shadows/textures/effects/AA/foliage) + motion blur toggle + window mode;
Controls = rebindable key list (UMT2KeyBindingSubsystem, persisted in
GameUserSettings.ini [MT2KeyBindings]) replacing the old fixed key layout.
